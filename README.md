# Lidia Create — modpack

Minecraft 1.21.1 · NeoForge · Create + addons, biomas, mobs, armas, QoL.

## Cómo jugar
1. Instala [Prism Launcher](https://prismlauncher.org/download/) e inicia sesión con tu cuenta Microsoft (Minecraft Java).
2. **Añadir instancia → Importar** → pega:
   `https://github.com/fredygui/lidia-modpack/releases/download/instancia/Lidia-Create.zip`
3. Botón **Jugar**: sincroniza los mods solo (packwiz) y entra directamente al servidor.

Dirección del servidor (por si entras a mano): `molecule-she.tun.ply.gg`

Dale a Minecraft al menos 8 GB de RAM (ya viene configurado).
